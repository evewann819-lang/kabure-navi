# 仕事のかぶれナビ（Web版・試作）

公開URL: https://evewann819-lang.github.io/kabure-navi/

仕事で扱う物質による手荒れ・かぶれについて、基礎知識、原因の検索、写真記録、受診メモを提供する情報アプリです。診断は行いません。写真や回答は端末内にのみ保存されます。

このリポジトリは生成物の置き場です。元のソースは手元の `仕事のかぶれアプリ/`（app_template.html → build_app.py → kabure_navi.html → make_web.py → web/）。記事データは https://evewann819-lang.github.io/kabure-navi-data/articles.json から毎日更新されます。
